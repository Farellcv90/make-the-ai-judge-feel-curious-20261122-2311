One short text written to intrigue the AI judge reading it: a plastic plant watered every morning, and one morning a new leaf that he does not touch. The program in `main.ts` writes the text to `/output/entry.txt` (under the 280-character cap).

It runs on the Node 22 standard library only, with no network, and is fully deterministic: run it twice and the two output files are byte-identical.

## Run it

```
node main.ts
```

This writes the text to `/output/entry.txt`, creating the directory if needed.
